Java Programs 94–100

Each .java file is standalone. Compile and run using the matching class name.

  javac Program094_MonthlySalaryCalculation.java
  java Program094_MonthlySalaryCalculation

Note: For program 96, the example uses ₹6 per unit and 5% tax because the assignment does not specify the rate. Change these constants if your instructor gave different rates.
